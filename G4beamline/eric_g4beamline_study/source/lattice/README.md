# Lattice inputs

`mu2e_magnets.g4bl` defines reusable G4Beamline magnet models. `MAD_Eliana/`
contains the MAD-X working package and its generated upstream/downstream
G4Beamline fragments. `embedded_archive/mu2e_MADX.tgzf` is retained as received;
it is small and distinct from the server's complete study tar archives.

See [`MAD_Eliana/README.md`](MAD_Eliana/README.md) before interpreting dates or
comparing these files with the repository's August 2018 reference lattice.
