# Historical reference results

This directory preserves Eric's tables, figures, and selected scan products.
They are reference artifacts for comparison and provenance; they are not a
fresh validation run.

- `tables/` contains transmission spreadsheets/CSVs and calculation workbooks.
- `figures/` contains standalone plots and PostScript output.
- `scan_outputs/` contains the small plots and log preserved alongside scan decks.
- [`large_outputs/`](large_outputs/README.md) contains two locally retained,
  Git-ignored phase-space PDFs.
